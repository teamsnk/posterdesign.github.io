Permission Rules

Important rules for camera, microphone and screen sharing.

01

User must grant permission

The browser asks the user before allowing camera or microphone access. Admin cannot silently approve it.

02

Screen sharing uses the native browser picker

The user chooses the screen, window or tab from the browser's own screen-sharing dialog.

03

No hidden recording

This project does not record camera, microphone or screen-share sessions. Live media disappears when the active session ends.

04

HTTPS is recommended

Production camera, microphone and screen-sharing features should run on a secure HTTPS website such as GitHub Pages.
