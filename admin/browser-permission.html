Chatter Privacy & Device Access

Device Permission

Chatter-এর Camera, Microphone এবং Screen Share ব্যবহারের permission এখান থেকে নিয়ন্ত্রণ করুন।

🔒 Privacy Protection
Admin/Super Admin কোনোভাবেই আপনার browser permission bypass করে Camera, Microphone বা Screen দেখতে বা শুনতে পারবে না। Feature ON থাকলেও আপনার নিজের browser permission প্রয়োজন হবে।
⚠️ Chatter System বর্তমানে OFF।
Administrator Chatter system বন্ধ রেখেছেন। System ON না হওয়া পর্যন্ত communication features ব্যবহার করা যাবে না।

Browser Controlled

🌐 Browser Permission

এই page-এর ON/OFF এবং browser-এর permission আলাদা। System Manager feature ON করলেও browser Camera, Microphone বা Screen Share permission block করলে device access সম্ভব হবে না।

Camera / Microphone কাজ না করলে:
1. Browser address bar-এর 🔒 icon-এ click করুন।
2. Camera অথবা Microphone permission খুঁজুন।
3. প্রয়োজন হলে Allow নির্বাচন করুন।
4. Page reload করুন।

Screen Share:
Screen Share শুরু করার সময় browser নিজেই screen/window/tab নির্বাচন করতে বলবে।
